Task Organizer

A task manager with user accounts, where each person only ever sees their own board. The part I like most is that tasks re-sort themselves: you pick an urgency when you create one, but as the deadline gets closer the task climbs on its own into Urgent and then Super urgent. The urgency you chose only acts as a floor, it never drops. It's deployed on Azure, with ASP.NET Core Identity handling registration and login.

Heads up: it's on Azure's free tier, so give it a moment to wake up. Feel free to create an account!

C# · ASP.NET Core · Razor Pages · EF Core · SQL Server · Azure

Try it live Code on GitHub

Game Backlog API

A REST API to keep track of my game backlog: what I want to play, what I'm playing and what I already finished. I built the schema code-first with EF Core migrations, wired the database context through dependency injection, and exposed full CRUD over REST, with a small board on top to actually see the backlog.

C# · ASP.NET Core · EF Core · PostgreSQL · Docker
